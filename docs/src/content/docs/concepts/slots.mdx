The `Slot` component is special because it allows players to take and place items
in the GUI. The player can freely move items between the player inventory and the
GUI, just like a vanilla container.

```java
private static Ref<Slot> SLOT_A;
private static Ref<Slot> SLOT_B;
private static Ref<Slot> SLOT_C;

...
.setup(r -> {
    SLOT_A = Slot.slot(r, SlotPos.of(1, 1));
    SLOT_B = Slot.slot(r, SlotPos.of(3, 1));
    SLOT_C = Slot.slot(r, SlotPos.of(6, 1));
});
```

## Getting / setting the `ItemStack`

You can get the current `ItemStack` in the slot using `getSlotItem(SLOT, gui)`
or `getSlotItem(slot)`. Similarly use `setSlotItem` to set the `ItemStack` in
the slot.

```java
ItemStack stack = getSlotItem(SLOT_A, gui);
```

```java
setSlotItem(SLOT_B, gui, stack);
```

## Many slots

In case you want to create a container that has a lot of slots, you can use a loop to create them.

```java
private static List<Ref<Slot>> LEFT_SLOTS;
private static List<Ref<Slot>> RIGHT_SLOTS;

public static final CustomGuiType TYPE = CustomGuiType.builder()
    .height(6)
    .setup(r -> {
        useTitle(r, "A lot of slots.");
        LEFT_SLOTS = new ArrayList<>();
        RIGHT_SLOTS = new ArrayList<>();
        for (int x = 0; x < 3; x++) {
            for (int y = 0; y < 6; y++) {
                LEFT_SLOTS.add(Slot.slot(r, SlotPos.of(x, y)));
                RIGHT_SLOTS.add(Slot.slot(r, SlotPos.of(x + 6, y)));
            }
        }
    })
    .build();
}
```

## Slots for specific items

You can also create slots that only accept specific items. For example, you can
create a slot that only accepts diamonds.

<Tabs syncKey="platform">
<TabItem label="Paper">
```java
.setup(r -> {
    DIAMOND_SLOT = Slot.slot(r, SlotPos.of(0, 0), slotCanHold(item -> item.getType() == Material.DIAMOND));
});
```
</TabItem>
<TabItem label="Fabric">
```java
.setup(r -> {
    DIAMOND_SLOT = Slot.slot(r, SlotPos.of(0, 0), slotCanHold(item -> item.is(Items.DIAMOND)));
});
```
</TabItem>
</Tabs>

## Slots for specific players

You can create slots that only specific players can use. For example, you can
create a slot that only works for players in creative mode.

<Tabs syncKey="platform">
<TabItem label="Paper">
```java
.setup(r -> {
    DIAMOND_SLOT = Slot.slot(r, SlotPos.of(0, 0), slotMayChange(player -> player.getGameMode() == GameMode.CREATIVE));
});
```
</TabItem>
<TabItem label="Fabric">
```java
.setup(r -> {
    DIAMOND_SLOT = Slot.slot(r, SlotPos.of(0, 0), slotMayChange(player -> player.isCreative()));
});
```
</TabItem>
</Tabs>

Another use-case may be creating a slot that can never be changed by players, to
display a static item in the GUI.

```java
.setup(r -> {
    STATIC_SLOT = Slot.slot(r, SlotPos.of(0, 0), slotMayChange(player -> false));
});
```

You can still set the item in the slot programmatically using `setSlotItem(STATIC_SLOT, gui, stack)`,
but players will not be able to change it.
